# 초보 담당자 실행 안내 검토 결과

작성일: 2026-09-15

## 결과와 범위

- 기존 검토 후보 **78/78**, 핵심 자체 서식 **3/3**의 제목·조건·확인 질문·증빙을 읽고 실행 안내를 작성했다.
- 각 항목에 쉬운 목표, 고유한 첫 행동, 실제 진행 단계, 구체적인 실제 증빙, 마무리 확인, 모를 때의 질문·도움 경로를 제공한다.
- REVIEW-001·002와 FORM_REGISTRATION은 **등록 준비**다. 실제 교육·선임·점검·개선 활동으로 이어져야 하며, 인원 입력이나 등록 완료를 법적 적용 확정·의무 이행으로 표시하지 않는다.
- FORM_PHOTO·FORM_PLAN은 **자체 기록 서식**이다. 사진 관찰과 직접 확인을 나누고, 계획은 실제 결정한 목표·담당·일정·예산만 적게 한다.
- 원본 카탈로그 ID·내용·CSV와 tasks.ts는 수정하지 않았다. 새 안내는 법령 적용 규칙이나 승인된 기술 작업 절차가 아니다. 새 법적 기준·교육시간·기한·필수 서식을 추가하지 않았다.
- 기존 자료에 나온 후보 범위를 사용한 편집 검토다. 현행 법령 원문 재검증이나 업종별 의무 전체 검증을 수행한 보고서는 아니다.

## 구현·연결 방법

- `src/domain/task-guidance.ts`: `taskGuidance(definition)` 및 `guidedTaskIds`를 제공한다. 지원하지 않는 ID에는 `undefined`를 반환하고 매 호출 새 배열을 반환한다.
- `src/components/task-guidance.tsx`: `TaskGuidance({ definition: TaskDefinition })`. 상태·브라우저 API 없이 서버 렌더링 가능하며 첫 행동과 목표를 바로 보여주고 나머지는 기본 접힘 `<details>`로 제공한다. 기존 스타일 클래스를 사용한다.
- 통합 담당자는 원하는 상세 화면에 `<TaskGuidance definition={definition} />`를 연결한다. REVIEW-003은 전용 위험성평가 흐름에서 안내가 겹치면 공통 컴포넌트를 생략할 수 있다. 데이터는 REVIEW-003에도 제공한다.
- 본 작업은 task-detail·task-forms·tasks.ts·CSS를 수정하지 않았다. 화면 통합 및 브라우저 시각 검증은 통합 담당 범위다.

## 완료 판단의 한계

안내가 있다는 것은 활동을 실제로 수행할 수 있는 전용 모듈이 완성되었다는 뜻이 아니다. 현재 안내는 현장에서 할 일과 준비할 자료를 구체화한다. 실제 참석, 선임, 측정, 보수, 승인, 외부 제출, 기관 접수는 각각의 근거가 필요하다. 모르는 값은 해당 없음으로 바꾸지 않으며, 위험 작업을 확인하려고 임의 진입·설비 조작·자재 해체를 하도록 유도하지 않는다.
