# 초보자 중심 서비스 핵심 원칙

적용 범위: 현재 업무 화면과 앞으로 추가할 모든 분야·서식·AI 안내. 목표는 서류 칸을 채우는 것이 아니라, 처음 맡은 담당자가 실제 해야 할 일을 이해하고 확인 가능한 기록을 남기는 것이다.

## 1. 설명은 다음 행동으로 이어진다

- 업무마다 목적, 먼저 확인할 사실, 현장에서 할 일, 남길 증빙, 다음 단계를 쉬운 말로 설명한다.
- 전문 용어는 처음 나올 때 풀어 쓴다. “위험요인을 확인하세요”에서 끝내지 않고 “작업 장소에서 다칠 수 있는 상황을 찾아 위치와 상황을 적으세요”처럼 행동을 안내한다.
- 담당자·일정이 확인되지 않았다면 누가 무엇을 확인해야 하는지 안내한다. 임의의 담당자나 법정 기한을 넣지 않는다.

## 2. 실제 업무와 기록을 함께 돕는다

- 사실 확인 → 준비 → 실제 수행 → 증빙 → 검토·보완 → 필요한 제출·보존의 흐름을 연결한다. 적용되는 단계는 업무별로 구분한다.
- 실제 입력·기록과 증빙·수행 이력을 먼저 배치한다. 법령 상세는 그 아래에서 필요할 때 펼치도록 한다.
- 입력·업로드·작성자 확인·활동 수행·사람 검토·승인·기관 제출·접수는 서로 다른 상태다. 저장이나 자료 검토 완료를 업무 전체 완료로 표시하지 않는다.

## 3. 확인된 사실과 모르는 내용을 구분한다

- 미응답·추가 확인 필요·해당 없음을 구분한다. 모르는 값은 빈칸이나 미확인으로 남길 수 있어야 한다.
- 사진에서 보이는 상황, 사용자에게 확인받은 사실, AI의 추정은 구분한다. 참석·서명·예산·점검값·수행·접수 사실을 만들어 채우지 않는다.
- 예시는 이해를 돕는 가상 자료임을 표시한다. 예시를 자동 입력하거나 자동 저장하지 않는다. 사용자가 실제 사실을 확인해 입력하고 저장해야 한다.

## 4. 필요한 정보를 순서대로 보여준다

- 첫 화면은 현재 할 일과 입력에 집중한다. 긴 설명·예시·조문·조사 출처는 펼침 영역으로 제공한다.
- 출처 확인 상태, 권한 제한, 저장 실패, 검토 중 제한처럼 현재 판단에 필요한 상태는 숨기지 않는다.
- 법적 활동 수행 의무와 기록·보존 의무를 구분한다. 자체 서식을 법정 서식으로 부르지 않으며, 조문 확인과 개별 사업장의 적용 판단도 구분한다.

## 5. 권한과 접근성을 업무 흐름 안에서 지킨다

- 조직·현장·민감자료·역할별 권한을 서버와 자료 접근에 적용한다. 프로필 확인, 검토 중 편집 제한, 과거 버전 보호를 화면 변경 때도 보존한다.
- 입력 레이블, 키보드 이동·펼침, 보이는 포커스, 읽을 수 있는 대비를 제공한다. 색상만으로 상태를 전달하지 않는다.
- 좁은 화면과 확대에서도 입력·증빙·다음 행동을 사용할 수 있어야 한다. 오류는 원인과 가능한 다음 행동을 알리고 입력을 보존한다.

## 6. 완료 판단 기준

- 초보자가 무엇을 확인하고 실제로 무엇을 해야 하는지, 무엇이 아직 미확인인지 설명할 수 있다.
- 실제 입력 → 저장 → 증빙 → 수행 기록 → 검토·보완의 해당 흐름을 검증한다. 예시가 사실로 저장되지 않고 상태와 권한이 유지되어야 한다.
- 화면·DOM·키보드 순서에서 기록과 증빙이 법령 상세보다 앞선다. 근거는 기본 접힘이며 확인 상태와 원문·조건은 확인 가능하다.
- 실행한 검사와 결과, 미실행 검사와 사용자 참여 검증 여부를 구분해 보고한다. 화면 구현만으로 실제 업무 이행이나 법적 적합성을 보장하지 않는다.
