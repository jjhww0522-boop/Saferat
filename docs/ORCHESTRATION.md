# 오케스트레이션 실행 계획과 현재 상태

2026-09-14

## 현재 결과
Orca는 설치되어 있으나 기본 셸 PATH에서 CLI를 찾지 못했다. 설치된 resources/bin/orca.cmd 실행은 PATH/Path 중복 오류, 중복 키 이름을 정리한 자식 프로세스 실행은 20초 시간 초과였다. 런타임 task/dispatch는 생성하지 못했다. 이번 P0/P1은 단일 에이전트가 순차 구현했다. 별도 에이전트 검토·Orca 오케스트레이션 실행 완료로 보고하지 않는다.

## 복구 후 구성
총괄 1 + 작업자 최대 3. 총괄이 공통 데이터 계약·패키지·잠금·통합을 소유한다. 도메인 작업자는 규칙·상태·시험, UX 작업자는 회원 화면·디자인, 저장/운영 작업자는 서버 저장·검토를 소유한다. 작업 종료 후 다른 담당자가 교차 검증한다.

1. CLI status와 실제 런타임/기능 상태 확인.
2. 기반 커밋 후 독립 작업별 worktree 생성, 현재 미커밋 변경이 필요한 작업은 기존 작업 공간에서 수정 범위를 분리.
3. task-create로 입력·산출물·수정 범위·선행 작업·시험 기준 등록.
4. dispatch --inject로 단일 터미널에 배정. 작업자가 유효한 taskId/dispatchId로 완료/차단 보고.
5. 총괄은 task-list/dispatch-show로 완료 기록을 확인하고 통합 시험. 작업자의 자기 완료 보고만으로 출시 판단 금지.

작업 수가 적거나 공통 계약이 바뀌는 시점에는 병렬 실행 수를 줄인다. 실제 법령 승인 권한은 코딩 에이전트 역할과 별개다.
