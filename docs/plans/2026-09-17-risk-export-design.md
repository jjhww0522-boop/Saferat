# 위험성평가 버전별 내보내기

진행 기록의 다음 항목 중 외부 계정 없이 완성할 수 있는 내보내기를 먼저 구현한다. 사용자의 계속 진행 지시와 AGENTS.md의 저위험 기본값 원칙으로 진행하며 기존 미커밋 변경을 보존한다.

## 선택한 범위

- 저장된 현재/과거 버전을 지정해 HTML(열기·인쇄·브라우저 PDF 저장)과 JSON(원본 내용과 구조화 기록)을 내려받는다. 화면만 인쇄하면 접힌 위험요인과 미입력 항목을 놓칠 수 있으므로 별도 정적 보고서를 만든다. 서버 PDF 생성은 새 의존성과 실행 환경이 필요해 이번에 도입하지 않는다.
- 모든 평가 항목·위험요인·기존 답변·메모, 미입력 표시, 선택 버전의 확인·공개 검토 의견, 연결 증빙의 목록을 포함한다. 원본 첨부파일과 운영자 내부 메모·저장소 경로는 제외한다.
- 문서 전체 수행 이력은 내보낸 시점의 공통 이력으로 표시한다. 과거 버전 작성 당시의 상태나 해당 평가 회차의 수행으로 추정하지 않는다.
- 서버가 실행 모드를 결정한다. 실제 모드는 인증·기존 DB 읽기 권한·감사 조회 RPC를 적용한다. 버전은 반드시 해당 문서 소속인지 먼저 검사한다. 응답은 private/no-store, attachment이며 HTML은 사용자 입력을 이스케이프하고 외부 리소스/스크립트를 사용하지 않는다.
- 다운로드 안내에는 저장 후 파일을 열어 내용 확인 → 증빙 원본 함께 보관 → 실제 보관 위치 기록을 연결한다. 미저장 입력은 포함하지 않는다. 내려받기를 장기 보존 보장·사람 승인·기관 접수로 저장하지 않는다.
- 데모는 가상 자료임을 표시한다. 기존 자료 버전과 상태는 변경하지 않으며, 실제 서비스 조회 감사는 기존 `safety_read_version`을 재사용한다. 다운로드 완료 자체의 수신 확인 이력은 만들지 않는다.

## 구현·검증 순서

1. 공유 필드 표시와 내보내기 생성 → 원본·미입력·과거 기록·HTML 입력 이스케이프 단위 검사.
2. 인증된 다운로드 경로와 저장 자료 링크 → 다른 문서 버전·타 조직·민감자료/읽기 권한 차단, 비공개 필드 제외 검사.
3. 저장→보완→과거 버전 다운로드 → Playwright 실제 파일 다운로드·인쇄 표시·상태 불변 검사, 전체 단위·DB·lint·빌드 확인.

## 후속 범위

반복 회차 원장, 대량 내보내기, 법정 보존기간/기산 자동 계산, 실사용 장기 저장·운영 복구, 업종별 발굴 안내와 교육 전용 흐름은 남긴다. 내보내기는 선택 자료의 사본이며 서비스 전체 복원 기능이 아니다. 법령 해석·자동 적용 규칙은 변경하지 않는다.
