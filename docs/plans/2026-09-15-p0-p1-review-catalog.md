# P0·P1 실행 및 검토 목록

사용자 요청: 기존 P0·P1 수행, 업종별·인원별 체크리스트·점검·교육 등 검토할 내용 목록화.

## 구현 범위

- 기존 P0·P1과 디자인을 유지하고 실제 명령·브라우저로 완료 기준을 확인한다.
- 회원의 제공 범위 화면과 운영자의 법령 준비 화면에서 같은 검토 후보 목록에 접근한다.
- 업종·작업 조건·분류·검색으로 목록을 탐색한다. 인원은 검토 순서와 확인 질문에만 사용하고 항목을 자동 제외하지 않는다.
- 항목별 적용 조건, 확인 질문, 증빙 예시, 원문 조사 위치와 출처 확인 범위를 제공한다. 모든 항목은 적용 여부·전문 검토 대기 상태다.
- 다운로드에는 검토 상태와 출처를 포함한다. 원본 목록은 하나로 유지하고 문서도 같은 데이터에서 생성한다.

## 선택 이유

문서만 제공하는 방식보다 화면 검색과 다운로드를 함께 제공하면 여러 조건을 비교하기 쉽다. 자동 법적 판정은 승인된 규칙이 없는 현재 범위에 맞지 않는다. 이번 목록은 실행 규칙에 연결하지 않는다.

## 검증

- 0명·미응답·경계 인원을 구분하고 소규모 선택만으로 항목이 사라지지 않는지 확인.
- 업종 외 작업 조건으로 관련 위험이 검색되고, 필터 결과와 다운로드가 일치하는지 확인.
- 고객 제출 → 운영자 보완 → 회원 재제출 → 검토 이력과 고객 간 접근 차단 재실행.
- 타입·린트·단위 테스트·빌드·브라우저 검증, 모바일 목록과 키보드 접근 확인.

## 경계

P2 인증·DB·원본 파일, P3 승인된 실제 규칙, P4 실제 OCR·AI·PDF는 이번 P0·P1 완료와 구분한다. 외부 검토·사용자 참여 검증은 자동 테스트로 대체하지 않는다.
