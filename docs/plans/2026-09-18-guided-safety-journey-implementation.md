# 안내형 UX 구현 계획

2026-09-18 사용자가 설계안을 확인하고 “진행해봐”로 구현을 승인했다. 기존 미커밋 변경·저장본을 보존한다. writing-plans 스킬은 설치 목록과 로컬 검색에 없으므로 저장소의 계획·검증 규칙으로 실행 계획을 기록한다.

상태: 아래 1~5 구현·로컬 검증 완료. 단위 179개·DB 52개, 브라우저 시나리오 30개(전체 실행 29개 + 단독 재검사 1개)를 확인했다. 실패·수정 이력과 실제 연결·사용자 시험의 남은 범위는 [진행 기록](../PROGRESS.md)에 보존한다.

1. 공통 안내 정의와 저장 기준 요약, 사용자별 위치 저장 → 단위·DB 권한/요약 일치 검증.
2. 안내 홈·전체 지도·목록 전환·첫 업무 추천 → 미완성 프로필에서도 지도 접근과 첫 행동 확인.
3. 사업장 입력과 위험성평가를 짧은 질문 묶음으로 분리, 도움말·저장 후 다음·재개 → 실패 시 입력/위치 보존, 기존 버전/동시수정 검증.
4. 자료의 목적·연결 버전·남은 확인과 검토 연결 → 저장/수행/검토/접수 상태 구분 검증.
5. 반응형 스타일·전환·팝업 접근성 → 모바일·키보드·모션 감소·전체 회귀 테스트, 로컬 미리보기 시작, PROGRESS 기록.

법령 내용과 판정 규칙은 변경하지 않는다. 사용자 참여 시험과 실제 Auth/Storage/파일 검사/복구 검증은 기존 미완료 항목으로 보존한다.
