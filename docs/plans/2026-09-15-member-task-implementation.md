# 회원 업무 목록과 중앙관제 분리 구현

사용자가 확정한 계획의 구현 기록. 기존 미커밋 작업을 보존한다.

1. 서버 운영자 등록·MFA·배정 검사, 별도 로그인, 공개 데모 역할 고정 → 직접 요청·권한 변조 검증.
2. 현장별 업무·후보 버전·문서 연결·탐색 조건 저장 → RLS·중복·동시 수정·원본 보존 검증.
3. 회원 홈의 분야별 목록, 모든 후보의 공통 기록, 핵심 자체 서식 3종 → 작성·재접속·증빙·보완 흐름 검증.
4. 크림·코랄 기반 화면, 상태·목표일·검색 복원 → 모바일·키보드·대비·회귀 검증.

전체 후보는 법적 적용 판정이 아니다. 자료 준비 목표일은 사용자 업무 일정이며 법정 기한이 아니다. 작성·실제 수행·사람 검토·접수 상태를 분리한다. 실제 Supabase와 파일 검사·운영 복구는 연결 여부와 검증을 별도로 보고한다.
