# 가독성·시각적 설명 구현 계획

2026-09-18 사용자가 “계획대로 진행해봐”로 [시각 개편안](2026-09-18-visual-readability-review.md)을 승인했다. 실제 저장소 CWD와 Git 최상위를 확인했으며 기존 미커밋 작업·이력은 보존한다.

상태: 아래 구현·로컬 검증 완료. 단위 179개·전체 브라우저 32개와 TypeScript·ESLint·프로덕션 빌드를 통과했다. 실제 고객 참여 시험·저속망/실기기 시험은 별도 대기이며 상세 결과는 [진행 기록](../PROGRESS.md)에 남긴다.

1. Pretendard 공식 v1.3.9 WOFF2와 OFL을 포함하고, 밝은 바탕·네이비 글자·파란 주요 행동 및 역할별 크기를 적용한다. → 실제 글꼴 로딩·실패 대체·모바일·확대·대비 검증.
2. 홈의 주 행동·분야 위치·남은 확인을 벤토로 구성하고 저장 자료는 목록으로 연결한다. → 기존 추천 순서·검색·기록 재열람과 실제 저장본 상태 유지 검증.
3. 위험성평가에 현장·사람·기록 설명 그림과 수동 3컷 도움말을 제공하고 모바일 지도는 미시작 업무를 펼쳐 보게 한다. → 키보드·모션 감소·예시 미저장·작성 내용 보존·실패/재시도/재접속 검증.
4. 대표 홈·입력 화면을 실제 캡처로 비교하고 기존 회귀 검사를 수행한다. → PROGRESS에 명령·결과·미연동·후속 작업과 로컬 주소 기록.

서버 업무 계산·권한·법령 규칙·증빙 상태는 이번 시각 변경으로 바꾸지 않는다. 실제 고객 참여 시험과 실서비스 연결은 이전 미완료 범위로 유지한다.
