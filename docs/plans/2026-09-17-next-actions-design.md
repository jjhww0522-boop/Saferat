# 다음 행동과 정확한 기록을 중심으로 한 개선 계획

2026-09-17 사용자 승인: 먼저 ‘필요한 일과 다음 행동’을 개선한다. 첫 법령 범위는 산업안전보건법과 중대산업재해로 잡고 중대시민재해는 별도 표시한다. 전 산업·전 규모 지향과 시설관리·유지보수부터 검증하는 기존 순서를 함께 유지한다.

## 제품 방향과 관점별 합의

사업장 정보 확인 → 관련 업무 이해 → 실제 행동·기록·증빙 → 검토·보완 → 보관을 한곳에서 이어가게 한다. 전 법령 완전 대응이나 법적 적합을 보장하지 않는다. 법령별 적용 단위·대상·예외를 하나의 인원 값으로 판단하지 않는다.

아래는 디자인·개발·운영 관점의 독립 에이전트 검토와 고객 관점의 사용 시나리오 검토다. 실제 부서 회의나 고객 인터뷰 결과가 아니다.

| 관점 | 제안과 우려 | 반영한 결정 |
|---|---|---|
| 고객 | 무엇을 먼저 해야 하는지, 저장했는지, 다시 어디서 찾는지 알아야 함 | 최대 3개 행동, 총 남은 수·전체 펼침, 입력칸 바로가기, 저장 상태 |
| 디자인 | 정보를 줄이면 경영책임자 업무와 미확인 항목이 사라질 수 있음 | 목록 구조 유지, 관리체계 진입 노출, 나머지 행동과 전체 후보 보존 |
| 개발 | 홈에서 문서별 상세 조회 반복 시 원문 노출·감사 중복·성능 문제 | 권한 검사 일괄 요약 RPC, 최소 데이터·요청당 요약 감사 1건 |
| 운영 | 검토 완료가 개선 완료로 오인되거나 과거 질문 의미가 바뀌면 안 됨 | 조치와 검토 분리, 저장 버전·작성자 확인 출처, 질문 원문 스냅샷 |

법령 전체 지도나 AI 자동 작성 확대보다 다음 행동→입력→저장→재열람을 먼저 연결한다. 실제 운영에 필요한 법령 승인·인증·파일·복구 준비는 별도 병행 항목이다.

## 1차 구현 범위

1. 홈: 사업장 요약 → 다음 행동 최대 3개 → 관리 현황·관리체계 진입 → 등록 업무·관련 후보·전체 후보. 추가 질문마다 해당 단계·첫 미확인 필드로 이동한다.
2. 우선순위: 미해결 개선조치(목표일 빠른 순) → 보완 요청 → 경과한/임박한 자료 준비 목표 → 미확인 정보·요약 → 초안. 대표 행동은 업무별 한 개이며 전체 상태는 아래 목록에도 표시한다.
3. 높은 위험도만으로 긴급 상황을 선언하지 않는다. 자료 검토 중·완료여도 미해결 조치를 표시한다. 검토 중에는 저장본으로, 편집 가능하면 개선 실행 단계로 연결한다.
4. 명시적 임시 저장을 유지한다. 변경·저장 중·완료·실패 표시와 이탈 확인을 제공하고 원문을 브라우저 영구 캐시에 넣지 않는다. 긴급 안내는 새 창으로 바로 연다.
5. 입력 영역과 저장본을 구분한다. 저장 내용·버전 이력은 펼쳐 볼 수 있으며 기존 버전 링크·다운로드 주소를 유지한다.
6. 새 답변은 당시 질문 ID·원문·정의 버전과 함께 저장한다. 질문 원문이 없는 기존 기록은 ‘당시 질문 원문 미보관’으로 표시하며 오늘의 질문을 임의로 붙이지 않는다. 서버가 기존 스냅샷을 보존한다.

`TaskActionSummary`는 서버에서 최신 저장본의 `TaskActionSource`로 계산한다. SQL·데모는 같은 사례로 비교한다. 본문·검토 의견·개인별 수행 메모는 홈 요약에서 제외한다. 미지원 형식을 완료로 해석하지 않는다.

## 후속 순서와 완료 기준

| 순서 | 결과물 | 완료 기준 |
|---|---|---|
| 다음 | 위험성평가 회차 원장 | 회차와 문서 수정 버전 분리, 이전 미해결 위험 연결, 과거 참석·수행일·완료 사실 자동 복사 없음 |
| 병행 | 법령 원장·규칙 승인 | 적용 조건·산정 단위·예외·시행일·공식 출처·검토자·기대 사례·배포/철회 이력·개정 영향 재확인 |
| 병행 | 실제 인증·저장·운영 검증 | Supabase·민감자료 권한·파일 검사·백업/복구·철회 시험, 운영자 배정·처리량/검토 기한 가시화 |
| 이후 | 교육 → 선임·역할 → 도급 → 점검·건강 | 분야별 실제 실행·증빙·보완·이력 흐름. 미검증 법정 시간·대상·기한 자동 확정 금지 |
| 후속 | OCR·AI 보조 | 원문과 후보 대조, 사용자 확인, 누락 보조. 이행·서명·예산·접수 사실 생성 금지 |

법령 승인과 외부 연동은 코드로 완료를 대체할 수 없다. 실제 적용 승인 규칙 0개, 세부 조문 미연결 73개의 준비 상태를 유지한다. 기존 출처의 확인 상태는 법령 조사 문서를 따른다.

## 검증

- 자동: 조치·검토 분리, 우선순위, 최신본, 질문 의미, SQL/TS 일치, 다른 고객·민감·읽기전용·운영자 배정 권한, 요약 감사, 입력 이동, 0/null, 저장 실패·복구, 링크·뒤로가기, 과거 버전·내보내기, 모바일·선택 접근성 규칙.
- 실제 사용자 시험(대기): 초보 담당자 5명 중 4명이 30초 안에 다음 행동을 찾고 저장→재열람 수행. 모든 참여자가 저장·검토·이행·접수의 차이를 설명하는지 확인한다. 자동 테스트로 대체하지 않는다.
- 브라우저 한계: 링크·새로고침/닫기는 이탈 보호를 제공한다. SPA 뒤로가기는 Navigation API 지원 브라우저에서 검증하며 구형 브라우저는 별도 개선 대상으로 남긴다.
- 실행 결과는 `../PROGRESS.md`에 기록한다. 위 완료 기준 자체는 실행 증거가 아니다.
