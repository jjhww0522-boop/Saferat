# 항목별 근거 법령 표시

사용자 요청: 각 서류·활동을 준비하는 조문 근거를 확인하는 칸을 추가한다.

- 목록의 긴 법령 열, 상세의 팝업, 상세 상단의 기본 펼침 영역을 검토했다. 모바일 목록 밀도와 접근성을 고려해 목록에는 짧은 근거 요약, 상세에는 기본 펼침 영역을 사용한다.
- 법령명·조항·활동/기록 의무 구분·서류와의 관계·적용 조건·확인한 시행본·확인일·공식 원문을 제공한다. 자체 서식과 조문 미확인 항목도 빈칸으로 숨기지 않는다.
- 기존 후보 출처를 보존한다. 확인된 원문만 조문 근거로 연결하고, 조사 위치만 있는 항목은 ‘조문 확인 중’으로 표시한다. 출처 열람은 법령 적용 승인으로 취급하지 않는다.
- 법령 조회는 기록 양식·저장·권한·법적 적용 판정을 변경하지 않는 읽기 전용 안내다. 기존 근거를 수정·승인하는 운영 도구나 전수 법령 조사로 범위를 확대하지 않는다.

검증: 모든 후보·자체 서식의 안내 상태, 원문 연결, 기록/활동 구분 → 단위 검사. 상세·기존 작성 업무·후보 목록·모바일·접근성 → 브라우저 검사. 빌드·린트와 진행 기록을 완료한다.
