## 시각·탐색 기준
- 크림 #faf9f5, 글자 #242a31, 주요 행동 #214fba, 보완 #865014, 긴급 #b52d32. 상태는 글자와 함께 표시한다.
- 한글 산세리프. 외부 폰트 요청 없이 로컬 Pretendard/Noto Sans KR/맑은 고딕 순으로 사용한다. 핵심 본문·입력 16px 수준, 제목 24~28px, 보조 표기 11~14px. 정보가 많은 업무 행은 모바일에서 요약한다.
- 회원 홈: 다음 행동 → 업무 목록 → 추가 정보/검토. 법령 근거는 상세에서 펼친다. 법적 준수율·안전 점수 없음.
- 모바일 하단: 홈 / 할 일 / 자료 / 검토·보완 / 더보기. 긴급 연락은 상단 별도 접근. 운영자는 오늘 검토 / 배정 고객 / 법령 준비.
- 중요한 입력·버튼 높이 48px, 보이는 포커스, 키보드 순서, 한글 레이블, 입력 중 오류 유지, reduced-motion 지원.
- 초안·내용 확인·수행 기록·검토 대기·보완·자료 검토 완료·접수 미확인은 서로 다른 의미를 유지한다.

## 초기 화면과 상태
- 홈·업무 상세·문서 버전·운영자 원본 비교·사업장 3단계 확인.
- 빈 목록, 저장 중, 저장 실패, 미배정, 접근 불가, 설정 실패, 만료된 체험, 추가 질문 제공.
- 가상 사진은 실제 현장 사진이 아닌 도식임을 표시한다. 실제 파일 선택 기능을 노출하지 않는다.
- 정보 작성 중 단계 이동은 화면만 전환한다. 별도 임시 저장으로 서버에 보존하며 저장 방식 문구를 표시한다.
