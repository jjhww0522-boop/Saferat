# 법령 조사·검토 준비 원장

2026-09-14 · 상태: 조사 계획 작성, 실제 조문 전수 조사·전문 검토 미실행

## 첫 범위
시설관리·유지보수 현장의 사업주·도급/수급 관계·실제 작업을 출발점으로 한다. 등록 업종이나 단일 인원 숫자로 확정하지 않는다. 전 산업·전 규모 목표를 유지한다.

| 조사 묶음 | 공식 원문 출발점 | 현재 상태 | 다음 작업 |
|---|---|---|---|
| 산업안전보건법 | https://www.law.go.kr/법령/산업안전보건법 | review_pending | 정의·적용·예외·하위 규정·별표·별지·위임 고시 연결 |
| 중대재해 처벌 등에 관한 법률 | https://www.law.go.kr/법령/중대재해처벌등에관한법률 | review_pending | 중대산업/중대시민재해 대상·책임·시행일·경과조치 각각 조사 |
| 시설·소방·전기 등 관련 안전 법령 | docs/06_SOURCES_DECISIONS.md 출발점 | 범위 미확정 | 시설·설비·계약 사실에 따라 조사 연결, 누락 추적 |

위 링크는 제공된 기획 문서에서 가져온 조사 출발점이다. URL 제공·도달과 본문 검토·규칙 승인은 독립 상태다. 이번 P1에는 승인된 실제 규칙이 없다.

## 검토 기록 계약
각 원문 버전의 조문마다 의무 추출 / 정의 / 예외 / 이유 있는 범위 제외 / 검토 대기를 기록한다. 각 의무는 책임 주체·적용 단위·필요 사실·조건·예외·기한 근거·수행·증빙·제출·보존으로 연결한다. 이후 규칙 버전과 정상·경계·미확인·과거 시점 기대 사례를 연결한다.

담당: 코딩 에이전트가 초안·시험 도구 준비 → 사용자가 현장 사실·규칙 1차 검토 → 필요한 분야 외부 전문 검토 → 권한 있는 검토/배포 기록. 자기 조사 결과를 에이전트가 승인하지 않는다.

## 확인 필요를 해결하는 방식
- missing_fact: 해당 질문과 응답 담당자에게 연결.
- unconfirmed_fact: 원문·후보·사용자 확인 화면에 연결.
- rule_unverified / interpretation_required: 검토 대상·이유·검토자를 운영 대기열로 연결 (P3).
- source_unavailable / scope_unresolved: 원문 확인·조사 범위 결정 과제로 추적 (P3).
- 미해결 상태를 완료나 비적용으로 제거하지 않는다. 해결 후 새 사실/규칙 버전으로 재평가하고 과거 결과를 보존한다.

## 현재 준비된 근거
DEMO_CHECKLIST_001 / DEMO_TRAINING_001 / DEMO_CONTRACT_001은 법적 의무가 아닌 명시적 체험 규칙이다. 가짜 조문·선임 인원·교육 시간·제출 기한을 사용하지 않는다. 실제 배포 관리·법적 기간 계산·자동 개정 영향 분석은 P3 미구현이다.
