# 개발 결정

2026-09-14 · 사용자 승인 계획의 P0 + P1 구현

- 확정 요구: 시설관리·유지보수 현장부터 검증. 전 산업·전 규모 목표 유지. 사용자 1차 법령 검토 후 외부 전문 검토 추가.
- 디자인: DESIGN-claude.md는 참고 원본으로 보존. 크림 배경·한글 산세리프·파란 주요 행동·주황 보완·빨간 긴급을 사용한다.
- 단일 Next.js App Router·TypeScript 앱. npm.cmd를 사용해 PowerShell 실행 정책을 변경하지 않는다. 패키지는 정확한 버전과 package-lock.json으로 고정한다.
- P1은 단일 로컬 Node 프로세스의 메모리 저장소. 서버 재시작/명시적 초기화 시 소멸한다. 고객·운영자 화면은 같은 저장소를 이용한다.
- 실제 업로드는 받지 않고 제공된 가상 사진·등록정보·문서 샘플만 사용한다. 데모 역할 선택은 인증이 아니다. 실사용·공개 배포 대상이 아니다.
- APP_MODE=live와 AI/OCR live는 미연동 오류를 명시하며 자동 mock 전환을 금지한다.
- 법정 의무를 흉내 낸 숫자·조문 대신 DEMO_ 규칙으로 업무를 체험한다. 일정은 가상 업무 목표일이며 법정 기한이 아니다.
- 운영자 검토 완료는 자료 검토만 뜻한다. 수행·문서 확인·외부 접수와 분리한다. 재제출은 기존 버전에 대한 의견을 보존한다.
- 법령 조사 준비는 P0부터 진행하되 승인된 법령 규칙은 현재 0개다. 전문 검토 전 자동 법적 판정을 공개하지 않는다.
- 실행 환경에 맞춰 Node 타입은 24 계열로 고정한다. ESLint 10은 TypeScript·React Hooks·Next 공식 플러그인을 직접 조합한다. eslint-config-next의 일부 전이 플러그인이 ESLint 10 API와 충돌하여 해당 구성 패키지를 제거했으며, 최종 구성의 lint 실행은 통과했다.
- 브라우저 검증은 빌드한 앱과 설치된 Microsoft Edge를 Playwright로 실행한다. Orca agent-browser 연결 시간 초과로 대체했으며, 브라우저 검증과 Orca 작업 배정 성공을 혼동하지 않는다.
- 200% 확대 확인은 1440px 화면의 절반인 720 CSS px·기기 배율 2 환경에서 레이아웃을 검증한 것이다. 실제 기기의 브라우저 확대 조작·사용자 참여 검증을 대신하지 않는다.
