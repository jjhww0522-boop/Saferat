# 01. 제품 요구사항과 범위

작성일: 2026-09-14. 이 문서의 기능·가격·배정 한도 중 ‘제안’은 법적 사실이나 확정 계약이 아니다.

## 1. 목표와 사용 흐름

현장 담당자가 법령을 일일이 찾아 서류부터 고르는 대신, 자신의 사업장 사실을 확인하면 해야 할 일을 안내받고 문서·활동·선임·교육·검사·신고·보완을 같은 서비스에서 관리한다.

핵심 흐름은 `등록 → 사실 확인 → 의무·추가 질문 → 자료 작성/실제 수행 → 증빙 → 검토·보완 → 제출·보존 → 변경 시 재평가`다. 작업 목록은 문서 이름 목록이 아니라 책임 주체·실행·기한·증빙을 가진 의무 목록이다.

## 2. 확정된 요구와 구현 가정

| 구분 | 내용 |
|---|---|
| 사용자 확정 | 제조·건설·시설관리 외 음식점·편의점 등 전 산업을 목표로 함 |
| 사용자 확정 | 소규모부터 500명 이상까지 다양한 규모 지원 |
| 사용자 확정 | 주사용자는 현장 담당자. 사업주·승인자·운영자의 역할 연결 |
| 사용자 확정 | 사업자등록증 업로드를 기본정보 입력 보조에 활용 |
| 사용자 확정 | 법령 근거와 필요 서류·선임·교육·제출 등 구체적 행동 제공 |
| 사용자 확정 | PDF·사진 등 증빙과 AI 보완 안내·문서 자동 작성 |
| 사용자 확정 | JH 중앙 관제, 초기 1인 검토, 유료 상품에 정기 사람 검토 포함 |
| 사용자 확정 | 초기 온라인 지원, 추후 현장 방문 확장 |
| 사용자 확정 | 무료 고객 확보 후 광고·제휴와 규모 있는 기업 구독 확대 |
| 사용자 계획 | 개발 후 사업자등록. 월 50만 원·약 1년은 잠정 예산 |
| 개발 기본값 | 한국어 모바일 웹, 신규 저장소는 Next.js·TypeScript·Supabase 구성안 |
| 개발 기본값 | 무료는 기본 자동 안내와 셀프서비스, AI·파일 사용량 한도 설정 |
| 개발 기본값 | 초기 결제·광고·기관 자동 제출은 비활성, 기능 권한 구조만 준비 |
| 미확정 | 서비스명, 주당 개발 시간, 외부 검토자, 실제 요금·무료 자격·운영시간·검토 주기 |

무료 자격을 단순히 ‘5인 이하’로 하드코딩하지 않는다. 법령상 인원 구간과 서비스 요금제 기준은 별개다. 원하면 전 규모 무료 베타를 제공할 수 있게 운영 설정으로 관리한다.

## 3. 사용자 역할

| 역할 | 사용 목적 |
|---|---|
| 사업주/고객 관리자 | 사업장 정보 확인, 구성원 초대, 담당자 배정, 승인, 조직 현황 확인 |
| 현장 담당자 | 오늘 할 일, 문서 준비, 사진·PDF 제출, 교육·점검·보완 기록 |
| 근로자 | 배정된 참여 확인·자료 제출. 독립 계정과 전자서명은 후속 확장 가능 |
| JH/운영 검토자 | 배정 고객 검토, 보완 요청, 정기 검토 결과, 상담·기술 A/S |
| 법령 관리자 | 조사·규칙 초안·검토·배포와 영향 분석 |
| 시스템 관리자 | 계정·보안·장애 관리. 고객 원문 열람 권한과 분리 |

앱에서 ‘관리자’라는 역할을 부여해도 법률상 안전관리자·관리감독자·경영책임자로 선임된 것이 아니다. 법적 역할과 로그인 권한을 별도 저장한다.

## 5. 첫 구현과 후속 구현

첫 실행(P1)은 회원과 운영자의 한 업무가 끝까지 이어지는 데모다. P2에서 실사용 저장·인증·권한을 연결하고, P3에서 법령 원장과 승인된 규칙, P4에서 실제 AI·OCR와 문서 출력을 연결한다. P5는 운영·사업화 준비다. 단계 정의는 `05_PHASES_TESTS.md`가 기준이다.

앱 첫 버전에 우선 포함할 문서 기능은 ‘등록 정보 확인표’, ‘사진과 확인 내용을 연결한 점검 기록’, ‘확인된 담당자·일정·예산을 반영하는 계획 초안’이다. 법정 서식이 아닌 경우 반드시 ‘자체 서식’으로 표시한다. ‘안전보건관리계획서’라는 이름을 모든 사업장의 공통 법정 문서로 고정하지 않는다.

후속 확장: 기업용 다수 사업장 보고·결재, 외부 검사·측정기관 협업, 근로자 참여, 현장 방문, 실제 결제, 공식 기관 제출 연동, 지원사업 매칭. 각 기능은 실제 필요·권한·데이터 확보 후 구현한다.

## 6. 무료·유료·광고 원칙

| 상품 | 구현 방향 | 확정되지 않은 부분 |
|---|---|---|
| 무료 | 기본 의무 확인·일정·서식·증빙, 제한된 AI | 대상 기준, 횟수·용량 |
| 유료 | 무료 기능 + 기업 관리 + 정기 사람 검토 | 가격, 검토 주기·분량·응답 시간 |
| 광고·제휴 | 사업자가 선택해 보는 관련 정보·제휴 영역 | 광고주, 과금 방식, 수익 규모 |

무료 고객을 유료로 전환시키기 위해 적용 의무를 누락하거나 과장하지 않는다. 사고 긴급 안내는 광고·로그인·결제로 가리지 않는다. 광고가 법적 판단 순위·검토 결과·필수 구매 여부를 바꾸지 못하게 한다. 고객 증빙·건강·사고 자료를 광고 타기팅 입력으로 사용하지 않는 것을 기본 정책으로 한다.

유료 사람 검토는 계약상 서비스 범위와 실제 검토 이력이 있어야 한다. 계약 검토 주기를 법정 교육·점검 주기와 혼동하지 않는다. 검토 가능 시간·대기량을 측정하고 신규 유료 고객 수용 한도를 설정할 수 있게 한다.

## 7. 운영 예산 기본안

월 50만 원 배정 예시: 개발 도구 10만, 인프라 10만, AI/OCR 7만, 메일·도메인 등 3만, 외부 검토 적립 15만, 예비비 5만. 실제 가격표가 아니며 JH 노동시간을 제외한다. 기존 도구 구독료 포함 여부는 미확정이다. 정부 지원금·광고 수익은 기본 운영 예산에 미리 더하지 않는다.

지출은 기능별 호출량·저장량으로 측정한다. 사용 한도는 서버에서 집행하며 고객 수 증가 시 비용 추정과 초과 방지를 먼저 확인한다. 단순히 무료 요금제를 쓰고 있다는 이유로 비용·보안·백업을 충족했다고 간주하지 않는다.

## 8. 성공 판단과 반대 가능성

제안 지표: 등록 완료율, 첫 의무 확인까지 걸린 시간, 첫 증빙 완료율, 다음 달 재사용률, 보완 처리시간, 고객당 AI·저장 비용, 고객당 사람 검토시간, 의무 누락·오분류 발견 건수, 기한 경과 건수. 정의와 집계 기간을 함께 표시한다.

반복 사용이 낮으면 가입자 수가 많아도 상품 가치가 검증되지 않은 것이다. 소상공인 편의 기능의 수요가 크더라도 기업의 통합 보고·권한·보안 요구는 별도로 검증한다. 전 산업 목표는 유지하되, 자동화 범위를 검증 없이 늘리는 것을 성장으로 평가하지 않는다.
